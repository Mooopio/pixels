03 / Camp Duration System

2-Week vs. 3-Week Model

2-Week Model

Pros

  • Easy enrollment
  • Fast commitment

Cons

  • Weak learning depth
  • Limited retention
  • Projects become rushed
3-Week Model

Pros

  • Stronger skill acquisition
  • Better friendships
  • Better habit formation
  • More impressive projects
  • Higher parent satisfaction

Cons

  • Slightly larger commitment
Recommendation

3 Weeks Per Round

Why? Educationally, this is the optimal learning cycle:

Week 1 = Learn → Week 2 = Practice → Week 3 = Build
04 / Weekly System

3 Days vs. 5 Days per Week

Option A — 3 Days/Week

Structure

Mon – Wed – Fri

Advantages

  • Easier logistics
  • Less burnout
  • Better for summer vacations

Disadvantages

  • Slower progress
Option B — 5 Days/Week

Advantages

  • Faster growth
  • Better immersion
  • Stronger community

Disadvantages

  • Fatigue risk
Recommended Model

5 Days/Week · Monday–Friday · 3.5 Hours Daily

Because:

  • Summer camp should feel immersive
  • Better project outcomes
  • Better retention
